# pixel-app

<!-- fixme: placeholder copy -->
A [pixel](https://pixelgui.com) app that runs in your terminal. Edit `src/main.tsx` to make it yours.

```
npm start
```

<!-- fixme: placeholder copy -->
`npm start` compiles `src/main.tsx` and runs it with `pixel .` in the current terminal pane. Press ctrl+c to quit.

<!-- fixme: placeholder copy -->
Your terminal needs the [kitty graphics protocol](https://sw.kovidgoyal.net/kitty/graphics-protocol/): Ghostty, kitty, WezTerm, cmux and others.
